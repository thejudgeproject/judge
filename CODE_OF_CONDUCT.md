# Code of conduct

This repository is about a cryptographic construction. The standard it holds contributors to is
the same one it holds itself to: say what is true, say what you are unsure of, and take
disagreement seriously.

## Expected

- Argue with the work. Attacks on the design are the most valuable thing anyone can bring here,
  and finding a flaw is a contribution, not an insult.
- Be precise. "This is wrong" plus the input that demonstrates it is worth more than a page of
  argument.
- Assume the other person read the specification and reached a different conclusion honestly,
  until you have reason to think otherwise.
- Accept a "no". Not every proposal fits the line this project draws between what is public and
  what is not, and that line is documented rather than improvised.

## Not accepted

- Personal attacks, harassment, or sustained hostility toward anyone taking part.
- Using this repository to pursue a dispute about the content of an entry in the archive. A
  report is a claim, and the right of reply on the site is the mechanism for answering it.
  Issues and pull requests here are not.
- Attempting to identify a filer, a responder, or anyone who maintains this project, or posting
  personal information about them.
- Publishing a vulnerability before it has been handled, or testing one against the live service
  in a way that touches other people's data. [SECURITY.md](SECURITY.md) sets out how to report
  one and what safe harbour applies.

## Reporting

Raise a concern through a
[private security advisory](https://github.com/thejudgeproject/judge/security/advisories/new) on
this repository. That channel is private, and it is the only private channel this project
operates. We do not publish a contact address, because an address published next to a project
about accusations attracts exactly what you would expect.

Anything that has to be escalated beyond this repository can be reported to GitHub directly
under their own policies.

## Enforcement

Maintainers may edit, hide, or delete comments and pull requests that breach this document, and
may block accounts from the repository. We will say when we have done so and why, unless saying
so would itself expose someone.
